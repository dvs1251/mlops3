# ml-git-dvc-project — Kidney Disease Classification (Git + DVC)

This is the iris project from `mlops_exp_3` rebuilt for **Kidney Disease
classification**, matching the structure and workflow of the "Dataset and
Model Versioning using Git and DVC" report.

## ⚠️ About the dataset

`data/cleaned_kidney_disease.csv` in this repo is a **placeholder**
generated by `data/generate_placeholder_dataset.py` — it has the exact
schema of the real UCI "Chronic Kidney Disease" dataset (25 columns: `age,
bp, sg, al, su, rbc, pc, pcc, ba, bgr, bu, sc, sod, pot, hemo, pcv, wc, rc,
htn, dm, cad, appet, pe, ane, classification`) and the same row counts used
in the report (**395 rows for V1, 400 for V2**), but the values are
synthetic. I generated this offline (I could not reach the internet from
the sandbox this repo was built in) purely so the whole pipeline below
already runs end-to-end.

**Swap in the real data** before you submit:
1. Download `chronic_kidney_disease.zip` from
   https://archive.ics.uci.edu/dataset/336/chronic+kidney+disease
   (or `pip install ucimlrepo` and fetch id=336).
2. Clean it into the same 25 columns and save it over
   `data/cleaned_kidney_disease.csv`.
3. Nothing else changes — `src/train.py`, `src/train_dvc.py`, `params.yaml`
   and `dvc.yaml` all just read that file by name.

## Prerequisites

```bash
pip install -r requirements.txt
```

You'll need `git` and `dvc` on your machine (both are in requirements.txt;
`dvc` wasn't installable in the sandbox that produced this repo since it
had no network access, so the actual `dvc init` / `dvc add` / `dvc repro`
commands below have **not** been run yet — do that from here).

## Step-by-step (mirrors the report, sections 3–19)

### 1. Init

```bash
git init
dvc init
```

### 2. Dataset V1 (395 rows)

```bash
python data/make_dataset_version.py v1
dvc add data/cleaned_kidney_disease.csv
git add data/cleaned_kidney_disease.csv.dvc data/.gitignore data/*.py .gitignore .dvc
git commit -m "Create cleaned kidney disease dataset V1"
```

### 3. Local DVC remote + push

```bash
dvc remote add -d localstorage ../dvc-storage
git add .dvc/config
git commit -m "Configure local DVC remote"
dvc push
```

### 4. Dataset V2 (400 rows, imputed)

```bash
python data/make_dataset_version.py v2
dvc add data/cleaned_kidney_disease.csv
git add data/cleaned_kidney_disease.csv.dvc
git commit -m "Create cleaned kidney disease dataset V2"
dvc push
```

### 5. Restore an earlier dataset state (optional, for the report's restoration section)

```bash
git log --oneline -- data/cleaned_kidney_disease.csv.dvc   # find the V1 commit hash
git checkout <V1_COMMIT> -- data/cleaned_kidney_disease.csv.dvc
dvc checkout
# ...and back to V2
git checkout <V2_COMMIT> -- data/cleaned_kidney_disease.csv.dvc
dvc checkout
```

### 6. Random Forest Model V1

`src/train.py` is already set to V1 hyperparameters
(`n_estimators=100, max_depth=5`):

```bash
python src/train.py
dvc add models/random_forest_kidney_v1.pkl
git add models/random_forest_kidney_v1.pkl.dvc models/.gitignore src/train.py
git commit -m "Add Random Forest kidney disease model V1"
dvc push
```

### 7. Random Forest Model V2

Edit `src/train.py`: change `RF_PARAMS` to
`dict(n_estimators=200, max_depth=10, random_state=42)` and `MODEL_OUT` to
`"models/random_forest_kidney_v2.pkl"`, then:

```bash
python src/train.py
dvc add models/random_forest_kidney_v2.pkl
git add models/random_forest_kidney_v2.pkl.dvc models/.gitignore src/train.py
git commit -m "Add Random Forest kidney disease model V2"
dvc push
```

(Afterwards you can revert `src/train.py` back to the V1 settings if you
want the committed file to match the "current" model.)

### 8. Hyperparameters + DVC pipeline

`params.yaml` and `dvc.yaml` are already in place. Commit them and run the
pipeline:

```bash
git add params.yaml dvc.yaml src/train_dvc.py
git commit -m "Add params.yaml and DVC pipeline for reproducible training"
dvc repro
git add dvc.lock metrics.json
git commit -m "Run pipeline, generate dvc.lock and metrics.json"
dvc push
```

### 9. Metrics comparison

```bash
dvc metrics show
# to diff two commits' metrics.json:
dvc metrics diff <COMMIT_A> <COMMIT_B>
```

### 10. Reproducibility check

```bash
git status     # should be clean
dvc status     # data/pipeline up to date
dvc repro      # should say "stage 'train' didn't change, skipping"
```

## What each file does

| File | Role |
|---|---|
| `data/generate_placeholder_dataset.py` | Builds the placeholder raw CSV (delete once you have the real dataset) |
| `data/make_dataset_version.py` | Materializes Dataset V1 (dropna) or V2 (imputed) as `cleaned_kidney_disease.csv` |
| `src/train.py` | Manual, hardcoded-hyperparameter training script for Model V1 / V2 |
| `src/train_dvc.py` | Pipeline-driven training script, reads `params.yaml`, writes `metrics.json` |
| `params.yaml` | Versioned Random Forest hyperparameters |
| `dvc.yaml` | Pipeline stage definition |
| `dvc.lock` | Exact dependency/parameter/output state (generated by `dvc repro`) |
| `metrics.json` | accuracy / precision / recall / f1_score |
